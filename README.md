# 🎮 Quebra Cabeça de 8 pastilhas
O quebra cabeça de 8 pastilhas é um jogo, onde o seu objetivo é reorganizar os números em ordem crescente (por exemplo, de 1 a 8) deslizando uma peça de cada vez para o espaço em branco. Ele é usado tanto para o lazer quanto no estudo de inteligência artificial e algoritmos de busca (como o algoritmo A*) para encontrar a sequência de movimentos mais rápida possível.

## 🚀 Como Compilar e Executar
Tenha um compilador C instalado (como o gcc). Use o terminal para executar.

## No Linux / macOS:
```bash
gcc main.c -o jogo
./jogo

## No Windows:
gcc main.c -o jogo.exe
.\jogo.exe

## Linguagens utilizadas:
* Linguagem C (Compilador GCC)
* Bibliotecas: stdio.h, string.h, time.h, stdlib.h.
